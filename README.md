# HTMLlings 🏷️

**HTMLlings** é uma plataforma interativa inspirada no *Rustlings / Ziglings* voltada para alunos e estudantes que estão aprendendo **tags HTML5**. 

Contém 20 exercícios práticos com validação em tempo real no navegador, feedback visual instantâneo e dicas amigáveis.

## 🚀 Como Executar Localmente

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev
```

Abra no navegador em `http://localhost:5173`.

## 📚 Conteúdo dos Exercícios (20 Desafios de Tags HTML)

1. **Títulos e Hierarquia** (`<h1>`, `<h2>`)
2. **Parágrafos de Texto** (`<p>`)
3. **Negrito e Itálico** (`<strong>`, `<em>`)
4. **Links de Navegação** (`<a>` com `href` e `target`)
5. **Inserindo Imagens** (`<img>` com `src` e `alt`)
6. **Lista Não Ordenada** (`<ul>`, `<li>`)
7. **Lista Ordenada** (`<ol>`, `<li>`)
8. **Criando Botões** (`<button>`)
9. **Campos de Entrada** (`<input>`)
10. **Rótulos de Formulário** (`<label>` e `id`)
11. **Formulários de Envio** (`<form>`)
12. **Caixas de Texto e Seleções** (`<textarea>`, `<select>`)
13. **Tabelas de Dados** (`<table>`, `<tr>`, `<th>`, `<td>`)
14. **Cabeçalho e Rodapé** (`<header>`, `<footer>`)
15. **Navegação e Conteúdo Principal** (`<nav>`, `<main>`)
16. **Seções e Artigos** (`<section>`, `<article>`)
17. **Imagem com Legenda** (`<figure>`, `<figcaption>`)
18. **Sanfona Retrátil Nativa** (`<details>`, `<summary>`)
19. **Destacando Código e Textos** (`<mark>`, `<code>`)
20. **Desafio Final: Página Semântica Completa**
